# JioBlackRock Mutual Fund Research

A source-backed overview of JioBlackRock Mutual Fund's publicly listed schemes, selected NAV data, and an investor due-diligence checklist.

## Project contents

```text
jioblackrock-mutual-fund-research/
├── README.md
├── report.md
├── data/
│   └── nav-snapshot.csv
└── sources.md
```

- [`report.md`](report.md) — research report, scheme-category overview, NAV snapshot summary, and due-diligence checklist.
- [`data/nav-snapshot.csv`](data/nav-snapshot.csv) — selected Direct Plan–Growth NAV values with the reported NAV date and source.
- [`sources.md`](sources.md) — official source links and notes on how to interpret the data.

## Research snapshot

- **Research date:** 15 October 2026
- **NAV date in the report:** 13 October 2026
- **Primary sources:** JioBlackRock Mutual Fund's official website and scheme documents, plus a SEBI-hosted scheme document.

The scheme list, NAVs, risk labels, offer dates, costs, and scheme terms can change. Check the latest official disclosures before using the information.

## How to use this project

1. Read [`report.md`](report.md).
2. Open `data/nav-snapshot.csv` in a spreadsheet application for further analysis.
3. Verify any scheme you are considering using its latest Scheme Information Document (SID), Key Information Memorandum (KIM), factsheet, addenda, and current NAV disclosures.
4. Record the date and source whenever you update the data.

## Important limitations

This is educational research, not a recommendation to buy or sell any mutual fund. It does not independently benchmark live fund performance, audit the fund house, or establish future returns. NAV per unit is not a performance ranking, and values from different schemes should not be compared as if they were prices of the same asset.

Mutual fund investments are subject to market risks. Read all scheme-related documents carefully. This repository is for informational and educational purposes only and is not investment, tax, or legal advice.
