## Data notes

- The CSV is a **snapshot**, not a live feed.
- The NAV figures in the report are described as **Direct Plan — Growth Option** values dated **13 October 2026**.
- NAV is a per-unit value; it should not be treated as a return percentage or as a way to rank funds.
- Scheme names, plan/option availability, riskometers, costs, exit loads, tax treatment and offer windows may change.
- Do not calculate performance from a single NAV observation. Use consistent start/end dates and distributions where applicable, and compare returns with the relevant benchmark and category.
- Before making an investment decision, review the latest SID, KIM, factsheet, addenda, portfolio disclosures, expense ratio, exit load and tax rules.

## Reproducibility checklist for future updates

When refreshing this project, record:

- Date and time accessed
- Exact scheme name, plan and option
- NAV date and value
- Source URL
- Benchmark and comparison period, if reporting returns
- Expense ratio, exit load and riskometer as shown in the latest documents
